# Тест конкурса из Telegram Admin

Обновите Windows PHOTO WALL командой `UPDATE-WINDOWS.cmd` и запустите сервер. Админка проверяет поддержку тестовых сессий перед включением.

Откройте `https://app.baliminsk.by/telegram-admin.html#tcTest`, войдите администратором и выберите одно или три призовых места. Нажмите «Включить новый тест».

1. Отправьте фотографии через «Король / Королева» в BALI Mini App на нужных устройствах. В тестовой сессии они автоматически одобряются.
2. В Telegram Admin нажмите «Голосование», затем проголосуйте через Mini App. Один голос на BALI ID в каждой тестовой сессии.
3. Откройте `https://baliminsk.online/live/contest`, выполните обычный вход оператора экрана. В админке задайте отсчёт (3–120 секунд) и нажмите «Отсчёт и победители». Экран покажет отсчёт, затем настоящий результат голосования и существующую анимацию корон. Для трёх мест нужны минимум три фото; для победителя нужен хотя бы один голос.
4. Нажмите «Завершить тест». Восстановятся сохранённые обычные настройки; тестовые фотографии не попадут в общий экран и обычную историю победителей.

Тест переключает конкурсные кнопки во всём Mini App: его следует проводить до начала обычного конкурса. Фотосервер должен оставаться включённым. Тестовые фото не отправляются в отложенную очередь: если связь прервана, повторите прямую загрузку после её восстановления.

Каждый новый тест получает отдельный идентификатор. Его подписанные пропуски загрузки не подходят другому тесту. Даты и расписания обычного конкурса не меняются.
