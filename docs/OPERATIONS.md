# Чек-лист открытия PHOTO WALL на вечеринке

## До прихода гостей
1. На компьютере клуба включить BALI PHOTO WALL: убедиться, что локальный адрес `http://127.0.0.1:3100/healthz` отвечает `{"ok":true}`.
2. Убедиться, что Cloudflare Tunnel `bali-photo-wall` имеет статус Healthy, а `baliminsk.online` открывается по HTTPS.
3. Войти на `/admin`, создать мероприятие с текущим названием и проверить его активность.
4. Войти на `/screen` с отдельным паролем экрана, включить полноэкранный режим и вывести изображение на LED-контроллер.
5. С обычного телефона открыть QR-ссылку, отправить одно тестовое фото и убедиться, что оно не показывается до одобрения.
6. Одобрить тестовое фото, проверить появление на LED-экране, после теста удалить.

## В течение вечеринки
- Проверять очередь фото в `/admin`; одобрять только снимки, пригодные для публичного показа.
- Удалять изображения по запросу гостя.
- Не вводить пароль администратора на гостевых устройствах.
- Если система зависла, проверить питание компьютера, Node.js-сервер и Cloudflare Tunnel.

## После вечеринки
- При необходимости закрыть активное мероприятие созданием следующего перед новым событием.
- Выключить LED-показ на экранах.
- Убедиться, что фотографии удаляются по установленному сроку `RETENTION_DAYS` (по умолчанию 7 дней).
- Резервное копирование, хранение персональных данных и правила публикации согласовать с ответственным клубом.

**Важно:** GitHub хранит только код. Фотографии и базу данных нужно хранить на сервере клуба; `.env` с паролями не публиковать.
