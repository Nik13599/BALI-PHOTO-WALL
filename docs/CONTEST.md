# BALI PHOTO WALL · Конкурс «Король и Королева ночи»

**Два существующих места исполнения, без второго сервера в клубе:** клубный компьютер Windows с PHOTO WALL (гостевые/конкурсные фотографии, модерация, LED-трансляция и отображение результатов) и инфраструктура действующего сайта baliminsk.by (регистрация, Telegram, проверка личности, голоса как основной источник данных, BALI Card, монеты и бонусы). Гостевые снимки загружаются на baliminsk.online, но остаются только на клубном компьютере. Фото конкурсанта передаётся с основной инфраструктуры по защищённому API для показа.

## Рабочие адреса после запуска Windows и подключения Cloudflare Tunnel

- https://baliminsk.online/ — загрузить обычное фото на экран через Telegram.
- https://baliminsk.online/admin — администрирование фотостены.
- https://baliminsk.online/admin/contest — заявки, кадрирование, награды и запуск конкурса.
- https://baliminsk.online/screen — LED-экран с мозаикой и конкурсом поверх неё.

Публичный HTTPS работает только когда запущены локальный PHOTO WALL, Cloudflare Tunnel и DNS направлен на него. Для локального компьютера используйте http://127.0.0.1:3100 с теми же путями. Установка подробно описана в WINDOWS_SETUP.md.

## .env только на клубном компьютере

CONTEST_BRIDGE_KEY — случайный секрет минимум 32 символа.
BALI_REWARDS_WEBHOOK_URL — только HTTPS endpoint на действующей инфраструктуре baliminsk.by (сервер BALI Card и наград). Адрес маршрута уточняется в основном репозитории; это не localhost и не отдельный сервис на клубном компьютере.
BALI_REWARDS_SECRET — отдельный секрет HMAC минимум 32 символа.

НЕ размещать секреты в Telegram Mini App, JavaScript браузера и GitHub. Адрес начислений пока не утверждён, это настройка для будущей интеграции. При отсутствии endpoint записи наград остаются в SQLite PHOTO WALL.

## Конкурс и экран

Администратор выбирает одно или три призовых места, соотношение конкурсных фотографий 1:1, 9:16 или 16:9, высоту и скорость движущейся ленты, срок голосования от 1 до 120 минут, BALI Coin и набор действующих бонусов для каждого места.

Заявки проходят отдельную модерацию; модератор меняет кадрирование. При запуске состав участников и настройки фиксируются. Во время голосования на LED поверх обычной мозаики непрерывно движется ряд участников справа налево. По истечении времени конкурсный ряд исчезает, победители появляются с золотой или золотой/серебряной/бронзовой короной. Обычная фотомозаика продолжает работать позади.

Победители определяются по количеству действительных голосов. При равенстве выигрывает более ранняя заявка, затем меньший ID. Если никто не голосовал, автоматический победитель не назначается.

## Приём заявок с доверенного регистрационного сервера

POST /api/integrations/contest-entry с заголовком X-BALI-Bridge-Key и multipart/form-data:

- photo: JPEG/PNG/WebP, до 8 МБ;
- externalId: внешний уникальный ID участника (3–100 допустимых символов);
- name: имя 2–70 символов;
- baliCardId: подтверждённый номер BALI Card ровно из 6 цифр;
- consent: yes.

Ответ 201 содержит entryId и pending. Нельзя напрямую отправлять запрос с браузера, пароль должен знать только доверенный сервер. Внешний сервер может принять предварительную регистрацию заранее, а импортировать её после создания конкурса в PHOTO WALL.

## Передача голосов

POST /api/integrations/contest-vote с заголовками Content-Type: application/json и X-BALI-Bridge-Key, тело JSON:

{"externalId":"person_12","voterId":"verified-telegram-user-123"}

**Основной источник голосов — база существующей инфраструктуры сайта BALI**, а не клубный компьютер. Сайт проверяет личность через собственную систему авторизации, сохраняет единственный голос и после успешной фиксации передаёт его через защищённый серверный API в PHOTO WALL для локального подсчёта/отображения. PHOTO WALL принимает зеркальную копию, сохраняет HMAC идентификатора, не открывает публичное голосование и отклоняет повторы. **Для коммерческого запуска необходимо обеспечить надёжную доставку или сверку итоговых голосов:** если связь пропадёт, зеркало на компьютере может отставать от сайта, поэтому победителей нельзя считать окончательно подтверждёнными без сверки с центральной базой. Такая серверная сверка ещё не реализована в этом PR.

## Передача наград в BALI Card

По завершении конкурса PHOTO WALL создаёт для каждого призового места, где есть ненулевая награда, отдельную неизменную запись в SQLite outbox.

POST на BALI_REWARDS_WEBHOOK_URL (только HTTPS на центральный сервер сайта BALI) с:
- Content-Type: application/json
- X-BALI-Reward-Id: bali-photo-wall:contest:19:place:1
- X-BALI-Signature: sha256=HMAC_SHA256(точные байты JSON, BALI_REWARDS_SECRET)

Пример тела запроса (числа и ID условные):

{
  "rewardId":"bali-photo-wall:contest:19:place:1",
  "source":"bali-photo-wall",
  "contestId":19,
  "eventId":42,
  "contestTitle":"КОРОЛЬ И КОРОЛЕВА НОЧИ",
  "entryExternalId":"person_12",
  "baliCardId":"001234",
  "place":1,
  "votes":121,
  "prizes":{
    "baliCoins":100,
    "bonuses":[
      {"code":"shot","quantity":2},
      {"code":"free_entry","quantity":1}
    ]
  },
  "finishedAt":1793300000000
}

Коды бонусов: free_entry (вход), shot (шот), cocktail (коктейль), hookah (кальян). Новые категории потребуют согласования с сервером карт.

Сервер BALI Card ОБЯЗАН проверить HMAC по сырым байтам JSON, полномочия победителя по Card ID, затем в атомарной транзакции обработать rewardId только один раз и сохранить ID обработанной операции. Повторные доставки того же rewardId должны возвращать подтверждение без повторного начисления.

Подтверждение после коммита: HTTP 2xx с JSON:
{"credited":true,"rewardId":"bali-photo-wall:contest:19:place:1"}

HTTP 200 без этих полей НЕ является подтверждением начисления. При ошибке соединения, таймауте, отсутствии корректного ответа outbox остаётся pending и автоматически повторяет отправку. Награды не начисляются напрямую приложением PHOTO WALL. До настройки серверного API BALI Card реальные начисления не подтверждены.

## Проверка

npm test проверяет старую фотостену и новый жизненный цикл конкурса. Перед внедрением на Windows нужно остановить сервер, сохранить .env и папку data, сделать резервную копию, применить обновление, запустить INSTALL-WINDOWS.cmd, добавить секреты в .env, проверить START-WINDOWS.cmd и Cloudflare Tunnel, затем провести тест с реальным сервером BALI Card.

## Размещение и ответственность

- **Клуб:** один Node.js-процесс BALI PHOTO WALL на Windows, локальная SQLite и каталог изображений; только он отрисовывает LED.
- **Существующий backend сайта BALI:** Cloudflare Pages Functions / D1 и Firebase по структуре репозитория BALI-MENU; конкретный продакшен-маршрут интеграции должен быть проверен в действующем развёртывании. Там хранятся учётные записи, голоса, BALI Card, BALI Coin и бонусы.
- **Подключение:** PHOTO WALL доступен через baliminsk.online по Cloudflare Tunnel, сервер сайта вызывает защищённые endpoints для заявок/голосов; PHOTO WALL сообщает результаты центральному HTTPS endpoint. Никаких отдельных локальных backend BALI Card или голосования на клубном компьютере.
- **Не смешивать данные:** сервер сайта не получает и не хранит обычные фотографии фотостены. Фотографии конкурсантов поступают отдельно после регистрации и согласия.
