# КОРОЛЬ / КОРОЛЕВА: конкурс по расписанию

Версия: 30.10.2026. Часовой пояс всех границ: **Europe/Minsk (UTC+03)**.

## Серверы

- **PHOTO WALL, baliminsk.online**: фотографии и превью, заявки, имена, ник Telegram, модерация, расписание, победитель. Файлы в `data/photos/`, локальная SQLite `data/bali-photo-wall.sqlite` на компьютере клуба. Фото **не** записываются в D1 BALI.
- **Telegram Mini App, app.baliminsk.by**: проверка BALI ID, выдача короткого подписанного билета для загрузки, строго **один голос на BALI ID и конкурс**. Только голоса хранятся в таблице `tg_photo_contest_votes` BALI D1. Новых записей в старую таблицу `tg_photo_contest_signups` больше не создаётся.
- **Итог**: PHOTO WALL запрашивает только суммарное число голосов за каждый ID фото, но **не** список голосовавших. В Telegram Admin есть закрытый журнал голосов с именем, номером BALI CARD, выбранным фото и временем.

## Расписание

- Регистрация и отправка одного фото: в любое время до **01:00**, пока конкурс включён и опубликована соответствующая вечеринка.
- С **01:00**: новые конкурсные фото не принимаются, начинается голосование за одобренных участников.
- С **03:00**: новые голоса сервером BALI отклоняются. PHOTO WALL запрашивает финальную ведомость, фиксирует результат в локальной SQLite, на отдельном LED-экране скрывает остальные снимки, показывает только фото победителя и анимацию золотой короны.
- Если несколько человек набрали равное число голосов, выигрывает тот, кто раньше зарегистрировал фото (затем меньший ID фото). Если нет ни одного действительного голоса, победитель не объявляется.
- При обрыве связи с BALI итог не подделывается: появляется «Подводим итоги», сервер повторяет чтение итогов, как только BALI восстановит доступ.

**Важная деталь даты:** дата голосования = календарная дата **после полуночи**. Для вечеринки 30 октября и голосования в ночь на 31 октября выбирайте **31.10.2026**, время 01:00–03:00. В поле BALI Event ID можно указать `2026-10-30` (или `2026-10-30__2`, если несколько мероприятий за день). При заданном ID чужие заявки отклоняются.

## Установка на Windows

1. Сохраните резервную копию `.env` и `data/` (удобно запустить `BACKUP-WINDOWS.cmd`).
2. Остановите сервер PHOTO WALL и запустите `UPDATE-WINDOWS.cmd` (или обновите исходные файлы с сохранением `.env` и `data/`).
3. Запустите `START-WINDOWS.cmd` и убедитесь в ответе `/healthz`.
4. Откройте `http://127.0.0.1:3100/admin`, войдите, выберите нужное мероприятие, раскройте **«👑 КОНКУРС · КОРОЛЬ/КОРОЛЕВА»**.
5. Включите конкурс, выберите **дату голосования**, начало **01:00**, конец **03:00** и (по возможности) точный **BALI Event ID**, затем сохраните расписание.
6. Отправка из Telegram Mini App сразу отправляет JPEG/PNG/WebP в PHOTO WALL. Одобрите фото до 01:00.
7. Для отдельного LED-экрана конкурса откройте `https://baliminsk.online/screen?feed=contest`. Обычные фото: `/screen?feed=regular`. Показ требует пароль оператора.

Обратите внимание: смена расписания после начала голосования блокируется. Создавайте отдельное мероприятие для проб.

## Быстрая проверка без ожидания до 03:00

1. Создайте **отдельное тестовое мероприятие** в PHOTO WALL, соответствующее опубликованной вечеринке BALI, и сделайте его активным.
2. В поле «Дата голосования» выберите сегодняшнюю дату по Минску и настройте **будущее** время начала через несколько минут и время завершения ещё через несколько минут (например 20:40–20:45, если в Минске ещё нет 20:40). Для реального режима затем создайте новое мероприятие с 01:00–03:00.
3. С двух разных зарегистрированных BALI ID откройте Telegram Mini App. С одного загрузите фото до старта, одобрите фото в /admin. При необходимости добавьте ещё одного участника таким же способом.
4. После наступления времени старта убедитесь, что загрузка закрыта, а голосование открыто. Попробуйте проголосовать повторно с того же BALI ID: число голосов не должно увеличиться.
5. После завершения LED-поток конкурса должен убрать остальные фотографии и показать победителя с короной. Сверьте сумму голосов в Telegram Admin с итогом PHOTO WALL.

Тест проверяет две системы. **Зелёный статус Cloudflare Tunnel не означает, что новые файлы PHOTO WALL установлены на компьютер.** Если приложение не обновилось после обновления сервера, нажмите Ctrl+F5 в окнах /admin и /screen.

## Точность и ограничения

- Закрытие голосования проверяется на сервере по абсолютному времени, а не по часам телефона. Держите часы компьютера Windows синхронизированными.
- Финализация запускается в 03:00, но фактическая анимация может появиться несколькими секундами позже из-за сетевых запросов и обновления LED-страницы. При недоступности источника голосов финализация будет позже.
- Для запуска нужны работающий Windows-сервер PHOTO WALL, Cloudflare Tunnel и опубликованная ветка Telegram Mini App.
- Начисление BALI COIN не входит в этот выпуск и требует отдельного защищённого финансового протокола.
