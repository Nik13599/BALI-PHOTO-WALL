# Фото-конкурс BALI: расписание с 30 октября 2026

По серверным часам Минска (UTC+03:00): в пятницу/субботу регистрация с 22:00 до 03:00 следующего утра. Голосование всегда начинается в 03:00. Конец голосования и время итогов выбираются в PHOTO WALL ADMIN, по умолчанию 06:00.

PHOTO WALL хранит все конкурсные фото на Windows-компьютере. Если сервер в сети, Telegram Mini App отправляет конкурсное фото напрямую на baliminsk.online, минуя облачное хранение. Если сервер выключен, файл временно помещается в отдельную Cloudflare KV очередь (не D1), максимум на 7 дней. Windows-сервер запрашивает доставку после запуска и каждые 45 секунд. Публичный Cloudflare обработчик отправляет фото **только** на фиксированный baliminsk.online; в ответе вызывающему фотографии не раскрываются. После подтверждённого приёма Cloudflare удаляет временную копию.

Заявка, отправленная вовремя, может приехать после открытия голосования, если Windows-сервер был выключен. Такая фотография всё равно остаётся в модерации, но может не успеть участвовать в уже начатом голосовании. Для честного конкурса включайте сервер и проверяйте модерацию до 03:00.

После изменений на GitHub обновите Windows-приложение через UPDATE-WINDOWS.cmd, сохранив data и .env. Дополнительных секретов для очереди на Windows не требуется. Публикация Telegram Mini App в Cloudflare происходит отдельно из ветки release/bali-telegram-miniapp. Основной сайт baliminsk.by не изменяется.
